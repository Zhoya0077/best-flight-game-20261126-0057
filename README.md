**Skyline Courier** — a chase-view flight game over an island archipelago. Fly the gold rings, mind the fuel, and bring her home to the runway. Three missions (Ring Run, Island Hop, Storm Courier), three lives, a live HUD with altitude, speed, heading, artificial horizon, fuel and throttle, and synthesized engine sound — all in plain static files, no network, no build step.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Or serve `game/` with any static server and open `game/index.html`. Keyboard (arrows/WASD, Shift/Ctrl throttle, Space brake), mouse or touch drag to steer. `?shot=start|play|rings|end&seed=7` renders one frozen frame for screenshots.
